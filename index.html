Rules in force
Credit structure T-P-PR summed (0-4-0 → 4, never 0)  ·  Per-semester credit sum must equal the semester's printed CREDITS line — checked first; a transcript is rejected before any SGPA is computed if it fails. This doubles as the parse-integrity check: if the two-column reader had mis-assigned a row, the credits would not reconcile and the student is held back rather than silently mis-audited.  ·  SGPA = Σ(Ci × Gi) ÷ ΣCi, 1 decimal, ROUND_HALF_UP  ·  CGPA recomputed from every subject across all semesters, not from the printed SGPAs  ·  Grade re-derived from marks and checked against the printed letter.
Derived totals: Total Credits = Σ(T+P+PR), Obtained Marks = Σ subject marks (with per-semester subtotals), Maximum Marks = subjects × marks-per-subject, Percentage = Obtained ÷ printed Maximum × 100. A Maximum Marks anomaly is reported, never silently substituted.
Arithmetic: every value is an exact fraction of two BigIntegers. No IEEE-754 float and no tolerance window in the rounding path — a value either matches or it does not. Printed figures are compared at the precision they were printed.

What this page checks
Verifies learner-identity data on each gradesheet against the Learner/TR sheet, matched by Registration No. — Student Name, Father's Name, Mother's Name, Date of Birth, Aadhaar (last 4) and ABC ID. Names must be proper text (trimmed, alphabetic) — placeholders like blank, ".", "-", "X", "N/A", "null" are rejected as invalid. DOB, Aadhaar-last-4 and ABC-ID matching use the same rules as the main page. Works with both TR formats automatically.
Name comparison — trimmed, whitespace collapsed, upper-cased, punctuation and titles (MR, MRS, SHRI, SMT, LATE) stripped, then compared token by token: an identical token set is a MATCH; initials against the same full name in the same order is a PARTIAL; anything else is a MISMATCH. A placeholder on either side is INVALID and never counted as a match, even when both sides carry the same placeholder.  ·  DOB — read from dd/mm/yyyy, dd-mm-yyyy, yyyy-mm-dd, dd Mon yyyy and Excel serial dates, normalised to yyyy-mm-dd, so 01/07/2004 and 1-7-2004 agree; a genuinely ambiguous day/month pair is reported, never guessed.  ·  Aadhaar — all non-digits and masking characters removed, then only the last four digits compared; a full number is truncated before comparison and never displayed.  ·  ABC ID — non-digits removed, compared in full, and flagged as malformed unless exactly 12 digits.  ·  Photograph — located from the PDF's own image operators (not by guessing at pixels), then measured for position, size, aspect ratio, effective dpi, tonal range and detail.

What this page verifies
Independent of any gradesheet — it checks whether the TR itself is mathematically & structurally correct. Per subject: Total, Result, Grade Point (Gi), Letter Grade, Earned Credit, CiGi. Final: Total CiGi, Earned Credits, SGPA, Result/Remark, Total Marks, Percentage — each verified two ways (the Excel's own formula result and an independent manual re-computation); any disagreement is flagged. Supports both T-P-PR and no-T-P-PR TRs automatically.
A derived cell holding a hard-typed value with no formula behind it is reported even when the number happens to be right, because it will not survive the next edit. Marks above a column's own stated maximum, duplicated registration numbers, blank learner names, incomplete subject blocks and a T-P-PR that disagrees with its own credit total are all reported as structure findings.
